A practical 16-week program for becoming work-ready with Git, GitHub collaboration, CI/CD, security, open source, and technical documentation.

## Portfolio outcome

By the end, create verifiable public evidence through:

- Git commits and branches
- Issues, milestones, and project boards
- Pull requests and review discussions
- Merge-conflict resolution
- GitHub Pages deployment
- GitHub Actions workflows and failure analysis
- Repository security configuration
- An external open-source contribution
- An independent technical research report

## Recommended certification path

1. [GitHub Foundations — GH-900](https://learn.microsoft.com/en-us/credentials/certifications/github-foundations/)
2. [GitHub Actions — GH-200](https://learn.microsoft.com/en-us/credentials/certifications/github-actions/)
3. Choose a specialization: [GitHub Administration — GH-100](https://learn.microsoft.com/en-us/credentials/certifications/github-administration/) or [GitHub Advanced Security — GH-500](https://learn.microsoft.com/en-us/credentials/certifications/github-advanced-security/)
4. Optional broader cloud credential: [AWS Certified Cloud Practitioner](https://aws.amazon.com/certification/certified-cloud-practitioner/)

Always verify current exam objectives, prices, availability, and renewal rules with the official provider before scheduling an exam.

## How to use this repository

1. Read one week's objectives.
2. Perform the work in a public repository.
3. Save the resulting issues, pull requests, commits, workflow runs, releases, and research notes.
4. Update your portfolio README with links to the evidence.
5. Do not claim professional employment or peer-reviewed research unless that is accurate; describe this as personal projects, independent technical research, and open-source contributions.
